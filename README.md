# Speedtest — замерятель скорости интернета

Тестовое задание: скрипт принимает адрес, откуда скачивать (например,
ссылку на достаточно "тяжёлую" картинку), делает 10 последовательных
запросов, дожидаясь ответа на каждый, и печатает в консоль среднее время
запроса, объём скачанных данных и итоговую скорость в МБ/с.

## Запуск

Зависимостей, кроме стандартной библиотеки Python 3, не требуется.

```bash
python speedtest.py <URL>
```

Пример:

```bash
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/8/8c/Example.jpg
```

## Пример вывода

```
Запрос 1/10: 0.412 с, 512.3 КБ
Запрос 2/10: 0.398 с, 512.3 КБ
...
Среднее время запроса: 0.405 с
Скачано данных: 5.01 МБ
Скорость: 12.37 МБ/с
```
